YANTRA is a desktop app that turns a local kanban board into staged Claude Code sessions. Each task gets its own worktree and runs research, plan, code and review. You approve every stage, and YANTRA never merges.

You stay in charge of every step

The agent does the typing. You decide what ships.

A local board per project

Issues, labels, priorities, comments and attachments live in SQLite on your machine. You don't need a forge account.

Real Claude Code sessions

Every stage is the interactive claude CLI in a terminal you can watch, type into, or take over.

Approval gates

Each stage ends with an artifact: research notes, a plan, code or a review. You approve it, request changes, or send the task back.

Isolated worktrees

Each task gets its own branch and git worktree, so your checkout stays clean and several tasks can run side by side.

Review before you push

Read the diff and commits, then push the branch and copy the PR description. Opening and merging the PR is up to you.

Token and time metrics

See tokens, cost and agent time for each stage, task and project, with a status bar showing today's totals.

How it works

Take an issue from the board to a branch you can open a PR from in four steps.

Write the issue

Add it to the board with a body, labels and any files the agent will need.

Start a task

Pick a template, such as standard or quickfix. YANTRA creates the worktree and runs your setup commands.

Approve the stages

When a stage finishes, the card shows "Needs you". Read its output and approve it or send it back.

Push and open the PR

Review the final diff, push the branch, and open the PR on your forge.

Everything from the terminal, too

The yantra CLI covers every operation in the app, so another Claude Code session can manage your board while the window is closed. Open the app whenever you want to watch, or to take over a session that's stuck.

  • Starts in the background on the first command, with no window.
  • Same rules as the UI. The CLI goes through the same handlers, events and stored state.
  • yantra guide prints a workflow you can paste into a repo's CLAUDE.md.
# file an issue and run it through the pipeline
> yantra issue create "Fix retry storm" --column todo
> yantra task start PAY-12
> yantra task wait PAY-12
> yantra task cat PAY-12 plan.md
> yantra task approve PAY-12

# when it's ready
> yantra task diff PAY-12 --stat
> yantra task push PAY-12

Get started

Download the installer from Releases and run it. It installs for your user only, with no admin prompt.

Download for Windows
  • Git installed and on PATH.
  • Claude Code installed and signed in. YANTRA checks for it on first run.
  • The installer is unsigned. If SmartScreen blocks it, choose More info, then Run anyway.
  • For the CLI, add <install dir>\resources\bin to PATH.
